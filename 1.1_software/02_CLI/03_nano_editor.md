## ⭐ Activity 3: Editing Text with nano

### 🎯 Goal  
Learn to create and edit text files from the CLI.

### 📝 Tasks
1. Open `notes.txt` with nano:
   ```bash
   nano notes.txt
   ```
<img width="840" height="311" alt="image" src="https://github.com/user-attachments/assets/9e675a70-bccc-4faa-82c3-edcbf09f441b" />

2. Inside nano, write:
   ```
   This is my first Raspberry Pi CLI note!
   ```
   <img width="859" height="322" alt="image" src="https://github.com/user-attachments/assets/658f4ba2-a574-4797-87fd-456250124e8c" />

3. Save and exit using:
   - **CTRL + O** (save)  
   - **ENTER** (confirm)  
   - **CTRL + X** (exit)

<img width="809" height="347" alt="image" src="https://github.com/user-attachments/assets/defaddca-dd00-4da5-8d17-50a1f96a9cc0" />

4. View the file contents:
   ```bash
   cat notes.txt
   ```
